# Client Lead Management System - Mini CRM

A simple Mini CRM web application developed as part of the Future Interns Full Stack Web Development Internship.

## Features

- Admin login
- Add new leads
- View leads
- Edit and update leads
- Delete leads
- Lead status management
- Notes
- Follow-up dates
- MongoDB database storage
- REST API using Node.js and Express

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose

## Lead Status

- New
- Contacted
- Converted
